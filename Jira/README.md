# Tablero de Jira — Proyecto Oasis Stay

En este espacio se gestiona el seguimiento ágil del proyecto **Oasis Stay** a través de la plataforma Atlassian Jira Software.

## Introducción

Oasis Stay es una plataforma para la gestión y operación integral de servicios hoteleros desarrollada para la Institución Universitaria ITM en la asignatura *Diseño de Sistemas de Información*. El ciclo de vida ágil del proyecto, la planeación de sprints, la definición de épicas y las historias de usuario (US-01 a US-11 con sus respectivos criterios de aceptación y tareas técnicas asociadas) se administran y monitorean directamente en el tablero Scrum del proyecto.

### Información del Proyecto
- **Plataforma:** Atlassian Jira Software
- **Clave del Proyecto:** `SCRUM`
- **Nombre:** Oasis Stay
